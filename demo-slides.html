06METHOD, HONESTLY

Two caveats, before you ask.

Metric choice

ROUGE-L → BERTScore F1

ROUGE-L is lexical overlap — it punishes a model for paraphrasing a correct answer. Ours paraphrases. We demoted it to a secondary signal and adopted semantic similarity as primary, keeping faithfulness (0.91 grounded) as the lexical complement. Relative rankings between models are meaningful; absolute scores aren't comparable to RoBERTa-large BERTScore reports.

Perf numbers

CPU proxy ≠ WebGPU

Quality numbers come from Node ONNX Runtime CPU runs — quality-honest, perf-irrelevant. Tokens/sec on CPU says nothing about the production path. Real performance is the live demo you just watched: WebGPU, on the user's own GPU, per-run hardware captured.

Everything is reproducible: npm install && node evaluate_multi.mjs --mode all --oos — same harness, your machine.
